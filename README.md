# YSLRP Scroll Cinema v10 — Cloudflare Pages

This branch is an **isolated preview release** of the overseas YSLRP FiveM roleplay introduction site.

The publication file `index.html` is a complete self-contained release, with all styles, scripts, images, SVG identity art and a short motion clip embedded. No Node.js server, database, account, forum, external JS CDN or paid Cloudflare service is required.

## Deployment

- Connected project: `yslrp-immersive-site` (Cloudflare Pages)
- Branch: `release/scroll-cinema-v10` (preview)
- Framework preset: None
- Build command: none
- Output directory: repository root (`/`)
- Production branch: `main`; merge only after preview QA

## Features

Chinese/English language switch, scroll-controlled scene sequence, mask transitions, horizontal role exploration, scripted interactive RP scenarios, responsive mobile view, prefers-reduced-motion support, clear FiveM/KOOK entry links. All visuals are conceptual illustrations, not actual YSLRP server gameplay captures.

## Notes

A maintainable multi-file source and asset archive is also retained in the conversation artifact `yslrp-scroll-cinema-v10-cloudflare.zip`. This branch intentionally publishes the self-contained build to eliminate asset-path issues and simplify free static hosting.
